# 抖音侧栏窗口（Windows）

这是 DSH 抖音侧栏插件的**公开测试版源码**，不是正式发布版本。它尝试在 Windows 版 DSH 桌面应用中内嵌抖音网页，并通过修改 DSH 主程序来保留登录会话。

## 验证状态

- 已在本机 Windows、DSH 0.2.2-rc.1 环境下做过登录、完全退出后重启及界面测试。这些结果只说明当时本机测试环境的表现，不能代表所有机器或后续版本。
- **当前新安全版补丁尚未在真实安装的 DSH 上安装验证。**之前的本机登录、重启和界面测试不能作为该新版补丁的实机验证结果。
- 尚未在干净 Windows 机器上从零验证完整安装、登录、重启与恢复流程；其他 DSH 版本和环境也未验证。

## 支持范围与功能

仅面向 Windows 版 DSH 桌面应用及其桌面浏览器桥；普通浏览器中打开 DSH 网页版不能使用该内嵌窗口。目标功能是打开和关闭侧栏中的真实 Electron `webview`，以及在适配的持久会话中保留登录。网页能否正常使用、登录能否持续，还取决于 DSH、抖音网页、账号和本机网络等条件，不作保证。

插件不内置代理、中继或 DNS 改写。新安全版补丁只识别特定主程序代码及完整性状态；版本号相同也不保证构建内容一致。它不是通用补丁，不应推断能支持其他 DSH 构建。

## 获取与安装状态

当前公开的是实验性源码，**完整安装流程尚未经干净机器验证**，暂不提供正式安装命令。请先确认目标环境、权限和风险；不要把本说明当成在生产环境操作的指引。

持久登录需要主程序配合；未经持久化适配的会话在 DSH 退出后不会保留。补丁脚本提供只读检查，但当前新安全版尚未完成真实安装验证；检查通过也不等于安装或重启后一定成功。任何真正修改主程序的操作都应先取得用户明确同意，并保存和核对相应版本的原始文件。

## 补丁的作用与风险

- 补丁设计为修改 DSH 安装目录中的 `resources\app.asar`，而不是只修改插件目录。安装位置受系统保护时可能需要管理员权限；修改、备份和临时文件也会占用该目录的磁盘空间。
- 补丁仅针对工作区名精确为 `dsh-douyin-sidebar` 和 `dsh-douyin-webview` 的会话设计持久存储；前者使用 `<DSH_HOME>\browser\persistent\dsh-douyin-sidebar`，后者沿用历史目录 `<DSH_HOME>\browser\persistent\douyin`。两个目录不共享，新版侧栏首次使用通常需要重新登录。
- DSH 的插件共享客户端环境，桌面浏览器接口按工作区名而非插件身份区分会话。其他插件理论上可以请求同名工作区并访问该持久会话；不要在同一 DSH 环境运行不信任的插件。登录数据保存在本机，但本机账户、其他软件或插件的访问权限仍可能带来泄露风险。
- 补丁会检查主程序代码和归档完整性，并在不匹配或检查失败时拒绝处理；这些保护不保证发现所有故障，也不能保证修改后的 DSH 一定能启动。异常或中断仍可能造成启动失败、数据丢失或需要人工修复。
- **旧补丁不能直接升级到当前新安全版。**不要在旧补丁上强行覆盖或绕过不匹配检查；需先单独核实当前归档、DSH 版本及可信的原版文件，再制定恢复和验证方案。
- 自动恢复（`restore` / `-Restore`）已禁用：旧备份与当前归档没有可靠的版本绑定。不要直接用最新备份覆盖现有归档；需要先保存当前文件，核实备份来源、版本与完整性，再由有经验的人员单独处理。
- DSH 更新可能覆盖补丁，也可能改变代码导致补丁不再适用。更新后不能假设重新运行补丁即可使用，必须重新核实兼容性和风险。

## 间歇性哈希失败

本机对大量归档条目连续计算摘要时曾观察到偶发不一致，随后对部分条目重复计算未复现。**根因尚未确定**；现有测试不能排除硬件、运行环境或软件等原因，也不能证明文件一定完好。

补丁代码在摘要有争议时使用原生计算重试及纯 JavaScript SHA-256 进行额外比对。这是降低误判的措施，不是对数据完整性或故障根因的证明；检查失败时应停止操作并调查，不应绕过校验。

## 开发测试

开发过程中运行了界面、来源、恢复、补丁与 SHA-256 的内存模拟测试；这些测试不等同于真实 DSH 安装、真实网络或干净机验证。完整测试夹具包含从本机 DSH 归档提取的主程序，因第三方组件来源尚未逐一核实，本次公开版本不包含该夹具和依赖它的补丁测试。
